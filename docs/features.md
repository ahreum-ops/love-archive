각 기능의 동작, 담당 파일, 고칠 때 주의할 점.

## 우리집 냥이 키우기

- 파일: `src/lib/cats.ts`, `components/cat-room.tsx`·`cat-sheet.tsx`·`cat-sprite.tsx`
- 홈 방에서 두 냥이가 돌아다닌다. 냥이를 골라 밥·물·화장실을 챙기면 그릇까지 걸어가서 냠냠·할짝·쓱쓱, 누르면 젤리.
- **배고픔·물·똥은 저장하지 않는다.** 마지막으로 챙긴 시각(epoch ms)에서 계산 → 앱을 안 연 동안에도 시간만큼 줄어든다.
  - 밥 12시간, 물 10시간에 0, 똥은 6시간마다 하나(최대 3). 80 아래일 때만 다시 줄 수 있다.
  - 쓰다듬기는 하루 5번, 새벽 1~7시는 잠.
- 출석(사람별 연속 출석), 경험치·레벨(레벨마다 필요량 증가), 돌봄 기록 최근 40개.
- 생김새는 실제 두 냥이 무늬를 SVG 로: `tabby`(고등어+흰 블레이즈), `patch`(흰 바탕 얼룩).

### 냥이 배구 (`/play/volley`)

- 피카츄 배구 같은 1:1, 11점 먼저 내면 승리. 이 화면에선 탭바 숨김.
- 물리: `src/lib/volley.ts` — 화면·네트워크와 무관한 순수 계산 (코트 480×300, 중력·점프·스파이크).
- 화면·터치 조작: `components/volley-game.tsx`
- 실시간 대결: `src/lib/volley-room.ts` — Realtime 채널 `volley-<coupleId>`
  - presence: 누가 들어왔는지·준비했는지
  - broadcast: a(호스트)가 공·점수를 계산해 스냅숏을, b 는 자기 냥이 위치만 보낸다. 각 **초당 15번**(무료 요금제 메시지 한도 고려).
  - DB 에는 아무것도 저장하지 않는다.
  - b 화면은 좌우를 뒤집어서 내 냥이가 늘 왼쪽.
- 컴퓨터 상대 연습은 체험 모드에서도 된다.
- 주의: 미리보기 창이 숨겨져 있으면 `requestAnimationFrame` 이 안 돌아 게임이 멈춰 보인다.
- 호스트(a)는 b 냥이를 직접 움직이지 않고 받은 상태를 `syncRemoteCat` 으로 넣은 뒤, 사이사이(1/15초)는 `coastRemoteCat` 이 받은 속도로 이어 가며 쿨타임·스파이크 시간도 줄인다. (예전엔 쿨타임이 안 줄어서 b 는 첫 공 이후로 공을 못 막았다 — 2026-11-03 수정)
- 점검: `npm run check:volley` (`scripts/volley-check.ts`, 순수 계산으로 원격 냥이가 공을 계속 받는지 확인)

### 길쭉 냥이 (`/play/snake`)

- slither.io·Insatia 같은 뱀 게임을 냥이로. 둥근 맵(반지름 1250)에서 사료를 먹고 길어지고, 내 머리가 다른 냥이 몸이나 벽에 닿으면 끝. 이 화면에선 탭바 숨김.
- 엔진: `src/lib/snake.ts` — 화면·네트워크와 무관한 순수 계산 (몸은 마디가 앞 마디를 따라오는 사슬, 죽으면 몸이 사료로). 모두 같은 속도이고 달리기는 없다. 컴퓨터 냥이도 나와 같은 크기(10)로 태어난다..
- 화면: `components/snake-game.tsx` — 캔버스. 머리는 늘 똑바로 선 냥이 얼굴(가는 쪽을 봄, 달리면 ^ ^), 몸은 무늬별 줄무늬·얼룩. 길어질수록 화면이 조금씩 멀어진다. 오른쪽 위 순위, 왼쪽 아래 작은 지도.
- 조작: 화면 아무 데나 끌면 그쪽으로(조이스틱). 컴퓨터에선 마우스 방향, ← → 로도 돈다.
- **혼자 하기**: 컴퓨터 냥이 9마리와. 부딪히면 끝, 최고 기록은 이 기기 localStorage `love-archive:snake-best:v1`. 체험 모드에서도 된다.
- **둘이 경쟁하기** (서버 모드): `src/lib/snake-room.ts` — Realtime 채널 `snake-<coupleId>`, 냥이 배구와 같은 presence(들어옴·준비) + broadcast.
  - a(호스트)가 전부 계산해 **초당 10번** 스냅숏(머리 위치·길이 + 그사이 생기고 없어진 사료만, 3초마다 사료·이름 전체)을 보낸다. b 는 방향을 **바뀔 때만**(최대 초당 10번, 가만히 있으면 1초에 한 번) 보낸다.
  - b 기기는 받은 머리 위치로 몸을 그려 내고, 내 냥이는 내 조작대로 먼저 돌려 본 뒤 호스트 위치로 조금씩 당긴다.
  - 3분 한 판, 컴퓨터 냥이 7마리 포함. 부딪히면 2.5초 뒤 다시 태어난다.
  - 점수 = 이번 판 최고 길이 + 연인을 내 몸에 부딪히게 한 횟수 × 20 (`duoScore`, `RIVAL_BONUS`). 같으면 연인 잡은 횟수로.
  - 경기 중: 오른쪽 위 VS 점수판(나 ⚔️ 연인·지금 길이·남은 시간), 연인이 화면 밖이면 가장자리에 보라색 화살표(길이 표시), 서로 잡고 잡힐 때 큰 안내, 마지막 10초 카운트다운.
  - 판이 시작되면 둘 다 준비가 풀린다. 결과 화면의 '한 판 더'는 대기실로 돌아가 바로 준비 — 둘 다 누르면 다음 판. 결과 화면에서 나갈 땐 상대를 쫓아내지 않는다.
  - DB 에는 아무것도 저장하지 않는다.
- 점검: `npm run check:snake` (`scripts/snake-check.ts`, 컴퓨터 냥이 2분 굴리기·벽/몸 충돌·스냅숏 주고받기)

## 사진첩 (`/album`)

- 파일: `src/app/album/page.tsx`, `components/photo-sheets.tsx`, `src/lib/album.ts`·`sw.ts`
- 직접 올린 `photos` + 버킷 완료 사진 + 장소 사진을 모아 최신순·월별로. 여러 장 한 번에 올리기.
- 탭바 7칸이 한계라 홈 카드에서 들어간다.

### 갤러리 공유로 올리기 (설치된 안드로이드 PWA 전용, iOS 미지원)

```
갤러리 → 공유 → 러브아카이브
  → manifest share_target: /share 로 multipart POST
  → public/sw.js 가 가로채서 먼저 /album?shared=wait 로 303 리다이렉트
  → 그 뒤에 본문을 읽어 메모리 + 캐시 shared-photos 에 보관
  → 사진첩이 takeSharedPhotos() 로 서비스워커에 메시지(take-shared)를 보내 받아 감
  → 올리기 시트가 열린다
```

- 리다이렉트를 먼저 하는 이유: 안드로이드 크롬은 응답 전에 본문을 읽으면 `Failed to fetch` 가 나는 경우가 있다.
- `formData()` 가 실패하면 바이트로 받아 multipart 를 직접 나눈다. 갤러리에 따라 파일 type 이 비어 오므로 형식 검사는 하지 않는다.
- 실패하면 어느 단계에서 왜 실패했는지를 사진첩 안내에 그대로 보여 준다.
- 서비스워커는 앱 셸(`app-shell.tsx`)이 항상 등록한다.

## 채팅 (`/chat`)

- 파일: `src/app/chat/page.tsx`, `src/lib/chat.ts`
- 탭바 두 번째 칸(안 읽은 수 배지) + 홈 카드로 들어간다. 이 화면에선 탭바를 숨기고 ‹ 로 홈.
- 말풍선·읽음·사진·이모지·하트 반응·보내기 취소.
- **메시지는 AppState 가 아니다** — 쌓일수록 state 가 커지고 저장 충돌이 잦아지니까.
  - 서버 모드: Supabase `messages` 테이블 ([server.md](server.md#채팅-messages)).
  - 체험 모드: localStorage `love-archive:chat:v1`, 보내는 사람은 `profile.me`.
- 최근 40개(`PAGE`)씩 불러오고, 위로 올리면 이전 대화.
- 보내기는 낙관적 → 실패하면 메시지에 '다시 보내기'.
- 채팅 사진은 Storage `photos/<couple_id>/chat/`.
- 보내기·반응·보내기 취소마다 푸시. 받는 기기에서 **채팅 화면을 보고 있을 때만** 서비스워커가 알림을 안 띄운다.
  - 예전엔 보내는 쪽에서 presence 로 걸렀는데, 폰을 끄거나 다른 기기에 채팅이 열려 있으면 알림이 계속 막혀서 뺐다.

## 설정 · 계정

- 파일: `components/settings-sheet.tsx`, `login.tsx`, `setup.tsx`, `who-switch.tsx`
- 이메일+비밀번호 로그인, 비밀번호 찾기(재설정 메일 → 링크로 들어오면 새 비밀번호).
